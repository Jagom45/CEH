# Social Engineering

# Sniff Credentials using the Social-Engineer Toolkit (SET)
- Use the SET to create a phishing website that harvests user credentials. This task simulates how attackers clone legitimate websites to trick users into entering sensitive information, like usernames and passwords, for unauthorized access.
# Detect Phishing using Netcraft
- Install and use the Netcraft browser extension to detect phishing websites. This task helps in identifying and reporting fraudulent websites that attempt to trick users into revealing sensitive information by mimicking legitimate websites.
# Craft Phishing Emails with ChatGPT
- Use ChatGPT to craft realistic phishing emails designed to trick users into revealing sensitive information or performing unwanted actions. This task demonstrates how AI can be used to automate social engineering attacks, making them more convincing and widespread.
