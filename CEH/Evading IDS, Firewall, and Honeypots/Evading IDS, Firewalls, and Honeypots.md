# Perform Intrusion Detection using Various Tools
- This task demonstrates how to install and configure Snort for intrusion detection and set up rules to monitor for suspicious activity on the network. Participants will learn to analyze the alerts generated by Snort when intrusion attempts occur.

# Deploy Cowrite Honeypots to Detect Malicious Network Traffic
- Participants will deploy a honeypot to monitor network traffic and capture attack attempts. Cowrie will simulate a vulnerable SSH service, allowing attackers to interact with it while their actions are recorded for analysis.

# Evade Firewall though Windows BITSAdmin
- This task shows how attackers can use Windows BITSAdmin to bypass firewall restrictions and transfer files. Participants will create and deploy a malicious payload on the target system, demonstrating how firewalls can be bypassed.
