# Footprint the Web Infrastructure
- Learn how to gather information about the target web application, such as server details, open ports, and services. Use tools like Nmap, Telnet, and OWASP ZAP for web infrastructure footprinting and vulnerability scanning.

# Perform a Brute-force Attack using Burp Suite
- Perform a brute-force attack on a target WordPress web application using Burp Suite to identify valid login credentials.

# Perform Remote Code Execution (RCE) Attack
- Exploit an RCE vulnerability present in a WordPress plugin to execute arbitrary code on the target server and gain unauthorized access.

# Perform Web Application Hacking using AI
- Use AI-driven tools like ShellGPT to automate web application footprinting, vulnerability scanning, and attacks. This task demonstrates how AI enhances web application hacking by generating and executing attack commands.

The objective of the lab is to perform web application hacking and other tasks that include, but are not limited to:
