# Denial of Service

Perform DoS and DDoS Attacks using Various Techniques
- Utilize tools like ISB and UltraDDOS-v2 to perform DDoS attacks on a target machine. This task involves flooding the target with traffic using TCP flood techniques to overwhelm its resources, leading to service unavailability.

Perform a DDoS Attack using Botnet
- Orchestrate a DDoS attack using a botnet to overwhelm a target network. The attack uses compromised systems (bots) to flood the target with traffic. Learn how botnets execute large-scale DDoS attacks and how to identify malicious botnet activity.

Detect and Protect Against DDoS Attacks using Anti-DDoS Guardian
- Use the Anti-DDoS Guardian tool to detect and mitigate DDoS attacks. The task demonstrates how to monitor and block malicious traffic to protect critical services from being overwhelmed by a flood of network requests.
