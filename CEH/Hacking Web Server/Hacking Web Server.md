# Hacking Web Servers

- Footprint the Web Server
Learn how to gather information about a target web server using Netcat and Telnet. Perform footprinting to extract data such as server type, OS version, and services running on the server.

- Perform a Web Server Attack
Perform a web server attack by cracking FTP credentials using a dictionary attack and exploiting the Log4j vulnerability to gain remote access to the web server.

Perform a Web Server Hacking using AI
- Use AI-driven tools like ShellGPT to automate web server footprinting and attacks. This task demonstrates how AI can optimize and streamline common hacking techniques.

Module 13: Hacking Web Servers
