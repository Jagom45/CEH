# Sniffing

# Perform MAC Flooding using macof
- Use the macof tool to flood the CAM table of a network switch, forcing it to act like a hub and allowing you to sniff the network traffic. This task demonstrates how attackers can exploit switch vulnerabilities to capture network packets.

# Perform a DHCP Starvation Attack using Yersinia
- Use Yersinia to perform a DHCP starvation attack, flooding the DHCP server with requests and exhausting its pool of available IP addresses. This task simulates how attackers can disrupt network connectivity and perform a denial-of-service attack.

# Perform Password Sniffing using Wireshark
- Use Wireshark to capture network traffic and identify sensitive information such as login credentials. This task shows how attackers can intercept and extract passwords from unencrypted network traffic.

# Detect ARP Poisoning in a Switch-Based Network using Wireshark
- Use Wireshark to detect ARP poisoning attempts in a switch-based network by identifying duplicate IP addresses. This task demonstrates how network administrators can monitor and detect man-in-the-middle attacks.

# Detect Promiscuous Mode in the Network using Nmap
- Use the Nmap Scripting Engine to detect systems in promiscuous mode on the network. This task helps identify potential sniffers operating on the network, providing insights into how attackers capture traffic across multiple devices.
